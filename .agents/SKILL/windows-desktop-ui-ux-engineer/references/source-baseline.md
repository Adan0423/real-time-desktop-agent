# Baseline Sources

Estas fuentes son puntos de partida, no versiones congeladas. Si una decisión depende de actualidad, verifica la documentación vigente.

- Windows app design overview: https://learn.microsoft.com/windows/apps/design/
- Windows design principles: https://learn.microsoft.com/windows/apps/design/design-principles
- Windows design guidelines: https://learn.microsoft.com/windows/apps/design/guidelines-overview
- Windows App SDK: https://learn.microsoft.com/windows/apps/windows-app-sdk/
- WinUI 3: https://learn.microsoft.com/windows/apps/winui/winui3/
- Desktop app development: https://learn.microsoft.com/windows/apps/desktop/
- Windows development best practices: https://learn.microsoft.com/windows/apps/get-started/best-practices
