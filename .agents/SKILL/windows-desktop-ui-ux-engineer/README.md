# Windows Desktop UI/UX Engineer

Skill reutilizable para analizar, diseñar, implementar, modernizar y validar interfaces de aplicaciones de escritorio orientadas a Windows.

## Capacidades principales

- Proyecto existente o desde cero.
- Analysis First.
- Detección automática del stack.
- WinUI 3, WPF, WinForms, .NET MAUI, Electron, Tauri, React/TypeScript, Flutter Desktop, Qt/QML y otros.
- Investigación web adaptativa.
- Dirección visual elegida automáticamente según producto y usuarios.
- Selector Design-first / Code-first / Hybrid.
- Figma opcional.
- Generación y modificación directa de código UI.
- Refactor seguro y preservación de funcionalidad.
- Visual QA autónomo e iterativo.
- Accesibilidad, keyboard-first, resize, DPI y temas.

## Instalación

El archivo principal es `SKILL.md`. La carpeta `references/` contiene material que el agente debe cargar solo cuando sea necesario y `scripts/validate_skill.py` comprueba la estructura básica.

Para plataformas compatibles con Agent Skills, conserva la carpeta completa `windows-desktop-ui-ux-engineer/`. Si la plataforma permite subir una skill desde el equipo, usa el paquete ZIP o extrae la carpeta según lo que admita el cargador.

## Validación local

```bash
python scripts/validate_skill.py
```
